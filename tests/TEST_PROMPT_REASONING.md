# Тест: Комплексная проверка генерации и рассуждения по промту в чат

## Что проверяет

Тест отправляет промт в Architect, анализирует рассуждение системы и проверяет результат:

| Этап | Что проверяется |
|------|----------------|
| **1. Парсинг** | LLM корректно извлекает параметры из промта (этажи, размеры, материал, стиль) |
| **2. Рассуждение** | Pipeline выполняет шаги в правильном порядке (parse → geometry → texture → render) |
| **3. Генерация** | bpy-скрипт компилируется и содержит все элементы (стены, окна, крыша) |
| **4. Превью** | Рендер соответствует заявленному качеству |
| **5. Соответствие** | AI анализирует скриншот и сравнивает с исходным промтом |
| **6. Баги** | Поиск визуальных артефактов и дефектов |

## Быстрый старт

### Dry-run (без сервера, только логика)

```bash
cd AI_Arhitector
PYTHONPATH=. python3 tests/test_prompt_reasoning.py --dry-run "двухэтажный кирпичный дом 10x12 с балконом"
```

### С живым сервером (локальный)

```bash
# Сначала подними сервер:
docker-compose up --build -d

# Затем запусти тест:
PYTHONPATH=. python3 tests/test_prompt_reasoning.py \
  "современная спальня 6x8 в стиле хайтек" \
  --url http://localhost:8080
```

### С Render (production)

```bash
PYTHONPATH=. python3 tests/test_prompt_reasoning.py \
  "офис 5 этажей стекло плоская кровля 20x24" \
  --url https://architect.onrender.com
```

## Опции

| Опция | Описание | По умолчанию |
|-------|----------|--------------|
| `prompt` | Промт для генерации | (обязательно) |
| `--url` | URL сервера | `http://localhost:8080` |
| `--quality` | Качество рендера | `standard` |
| `--dry-run` | Без сервера (только логика) | `false` |
| `--no-screenshot` | Без скриншотов | `false` |
| `--output` | Путь для JSON отчёта | авто |



## Отчёт

Тест генерирует:
- **Текстовый отчёт** в консоли
- **JSON отчёт** в `.openclaw/tmp/test_report_*.json`

Пример JSON:
```json
{
  "test_name": "Комплексная проверка генерации и рассуждения по промту в чат",
  "prompt": "двухэтажный кирпичный дом 10x12",
  "passed": true,
  "reasoning": {
    "param_accuracy": 0.85,
    "pipeline_correct": true,
    "order_correct": true
  },
  "preview": {
    "has_3d_model": true,
    "prompt_match": true,
    "ai_match_score": 0.8
  }
}
```

## Интеграция в CI

```yaml
- name: Run reasoning test (dry-run)

```
