# ArchAI v10.2 🏗️

AI-архитектор — генерация 3D-моделей зданий по текстовому описанию через Claude API.

## Запуск

Откройте сайт, перейдите в **Settings** (⚙️), введите Anthropic API ключ (`sk-ant-...`) и начните описание:

- *двухэтажный кирпичный дом 10×12*
- *офис 5 этажей стекло*
- *деревянный коттедж с террасой*

## Деплой

Сервис работает через **GitHub Pages**. Claude API вызывается напрямую из браузера (ключ хранится в localStorage).

## Функции

- 🏠 3D-генерация зданий по тексту
- 📐 2D-планы этажей
- 🪟 Интерьер / экстерьер
- 📷 Анализ фото (загрузка изображений)
- 🔄 Поворот, зум, навигация по этажам
